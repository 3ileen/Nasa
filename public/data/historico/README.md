# NinaWillay data

- **Source:** NASA FIRMS — active-fire detections from MODIS Aqua (2002–2011) and VIIRS S-NPP / NOAA-20
  (2012 onwards). The satellite data were not generated by AI.
- **Processing:** Junior FC team pipeline in `data-pipeline/` (schema 1.2: harmonized series, 2003–2024
  baseline, calendar, ranking and gridded map), developed with AI assistance.
- **`regiones/`:** calendar and ranking for Peru's 25 departments. `regiones.json` and the compact copies
  of these files were prepared with AI-generated scripts (Claude, through Claude Code).

Full details on AI use: [AI_DISCLOSURE.md](../../../AI_DISCLOSURE.md).
