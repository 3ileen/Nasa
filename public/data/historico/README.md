# Datos de NinaWillay

- **Fuente:** NASA FIRMS — detecciones de fuego de MODIS Aqua (2002–2011) y VIIRS S-NPP / NOAA-20
  (2012 en adelante). Los datos satelitales no fueron generados por IA.
- **Procesamiento:** pipeline del equipo Junior FC (esquema 1.2: serie armonizada, línea base 2003–2024,
  calendario, ranking y mapa por celdas), desarrollado con asistencia de inteligencia artificial.
- **`regiones/`:** calendario y ranking de los 25 departamentos. `regiones.json` y la copia compacta de
  estos archivos se prepararon con scripts generados con IA (Claude, mediante Claude Code).

Detalle completo del uso de IA: [DECLARACION_IA.md](../../../DECLARACION_IA.md).
