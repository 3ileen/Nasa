# AI use disclosure

**NinaWillay** was developed with the assistance of artificial intelligence (AI) tools, as required by
the NASA Space Apps Challenge 2026 submission guide. The **Junior FC (Moquegua)** team defined the
problem, requirements, design and every decision, and reviewed and tested everything that was generated.

## Tools

| Tool                                            | Used for                                                                                                                                                         |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Claude** (Anthropic), through **Claude Code** | AI-assisted programming of the frontend and its documentation (details below).                                                                                   |
| **Lovable**                                     | Generated the initial project scaffold (TanStack Start template and the base components in `src/components/ui/`). No longer used: the app is deployed on Vercel. |

## Where and how AI was used

**Code (AI-generated, reviewed by the team)**

- `src/components/`: map, years × months calendar, "Top years" table, summary, period panel, legends and filters.
- `src/estado/`: state for period, region, language, theme and panels.
- `src/lib/`: data loading, map density, categories and CSV download.
- `src/styles.css`: visual design, light and dark mode, mobile layout.
- `src/lib/*.test.ts`, `src/i18n/*.test.ts`: automated tests.
- `vite.config.ts`, `vercel.json`: build and deployment configuration.

**Texts and translations (AI-generated)**

- `src/i18n/es.ts`, `src/i18n/en.ts`: interface texts in Spanish and English.
- `src/i18n/qu.ts`: Southern Quechua (Collao) translation. It is an **AI-generated draft** refined with
  the open lexicon [SimiAru](https://github.com/Andre031222/SimiAru) (CC BY-SA 4.0); it should be
  reviewed by a native Quechua speaker.

**Data**

- Satellite data come from **NASA FIRMS** (MODIS Aqua and VIIRS S-NPP / NOAA-20); they were not generated by AI.
- Processing and harmonization (the team's pipeline in `data-pipeline/`) were developed with AI assistance.
- `public/data/historico/regiones/regiones.json` and the copies of the department files were prepared
  with AI-generated scripts from that export.

**Documentation**

- `README.md`, `AGENTS.md` and this file were written with AI assistance.

## Where it is recorded (metadata)

- `package.json`: `description` and `keywords` (`ai-assisted`, `ai-generated-code`).
- Web page HTML (`src/routes/__root.tsx`): `<meta name="ai-disclosure">` and `<meta name="ai-tools">` tags.
- `public/data/historico/README.md` and the `generado_con` field of `regiones/regiones.json`.
